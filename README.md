# DeskLock: sito

Sito vetrina di DeskLock (Windows 10/11): https://yanpeace.github.io/desklock/

Vite + React + TypeScript + Tailwind v4 + motion. `npm run dev` per sviluppare, `npm run build` per la build.
Il deploy su GitHub Pages parte a ogni push su `main` (`.github/workflows/pages.yml`).
L'installer è pubblicato nelle Releases del repository.
